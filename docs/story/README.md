## 작성 과정

1. 두 트랙이 같은 조건(고정 설정 · 시스템 이름 · 레퍼런스 독창성 기준)으로 세계관을 각자 작성했다 — `drafts/world_track_a.md`(Opus), `drafts/world_track_b.md`(Sonnet).
2. 서로 상대 안을 리뷰했다 — `drafts/review_track_a.md`(Sonnet이 A안을), `drafts/review_track_b.md`(Opus가 B안을). 독창성 · 정합성 · 에셋 적합성 · 챕터 1 구성 · 구현 가능성을 10점 만점으로 평가했다.
3. 리뷰가 꼽은 강점을 남기고 지적된 모순 · 레퍼런스 유사점을 고쳐 하나로 병합했다(WORLD.md, CHAPTER1.md). 프로토타입 규모에 맞춰 존 4 · 신규 몬스터 4 · NPC 5 · 서브 퀘스트 5로 제한했다.
