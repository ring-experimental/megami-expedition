# MEGAMI EXPEDITION — 세계관 & 1장 시나리오 제안 (Sonnet안)

> 가제: **1장 「멈춘 시계의 서곡」** · 세계 이름: **카덴 반도(Cadenza Peninsula)** 외 · 한 줄 컨셉: **"세계는 하나의 박자로 돌아갔다. 박자가 멈춘 뒤, 기계들이 각자의 박자로 말하기 시작했다."**

---

## 0. 설계 원칙 (이 안의 뼈대)

1. **음악·박자·시간**이 세계의 공통 언어다. 시계탑(시간) + 태엽(반복) + 여신의 깃털(깃펜/악보) + 잉크(UI 모티프)가 한 줄로 이어진다.
2. **전투 메카닉이 곧 세계관**이다. 패링 = "상대 박자에 맞장구치기", 협상 = "서로 다른 박자를 맞추기", 영입 = "동조 계약", 깃털 = "화음이 이루어진 증표".
3. 악역은 "악"이 아니라 **다른 종류의 선의**(질서)다. 몬스터를 죽이지 않고 대화하는 게임이므로, 갈등의 핵심은 *"기계의 자아는 오류인가, 존재인가"*.
4. 프로토타입에 바로 얹을 수 있게: 존/몬스터/아이템 전부 현재 데이터(`units.ts`, `world.ts`, `items.ts`)와 충돌하지 않는 이름과 구조로 짠다.

## 1. 로그라인 · 테마 · 톤

**로그라인**
130년 전 모든 시계탑이 멈춘 뒤 야생이 된 기계들 사이에서, 증기검사 카이와 기계의 목소리를 듣는 마도사 리라는 "멈춘 시계탑"을 다시 울리려 한다. 하지만 탑을 깨우는 일은 세상의 모든 기계에게서 자아를 지우려는 정시회와 정면으로 부딪치는 일이다.

**핵심 테마**
- **경청**: 이기는 법보다 듣는 법. 패링과 협상은 같은 동작(상대의 리듬을 읽기)의 두 얼굴.
- **습관이 곧 영혼**: 같은 일을 오래 반복한 것은 마음을 얻는다. 기계도, 사람도.
- **정지 vs 각자의 박자**: 통일된 표준 시간의 안정과, 제각각의 박자가 가진 자유와 위험.

**톤**
- 따뜻한 아침 증기 같은 서정 + 약간 건조한 유머. 큰 비극은 낮은 목소리로, 코믹은 몬스터가 담당(대사 톤은 `negotiation.ts` 성격 문구 참조).
- 시각: 황동·먹색·깃털의 흰금(UI_BIBLE 모티프와 일치). 색 과잉 금지, 램프 불빛이 주조.
- 사운드 키워드: 초침 / 쉼표(정적) / 종소리 / 증기 한숨.

## 2. 세계 설정

### 2-1. 우주론: 여신, 에테르, 기계의 영혼

**여신 세이라(Seira)**
- 태초의 세계는 "소리 없는 덩어리"였다. 여신은 세계를 *박자*로 쪼개 흐르게 했다. 이것이 시간의 기원이다. 여신은 "만든 자"가 아니라 **첫 박을 친 자(조율자)**.
- 여신의 흔적은 **깃털**로 남는다. 깃털은 "두 개의 서로 다른 박이 한 화음으로 겹칠 때" 어디선가 한 장씩 떨어진다고 전해진다(종교적 설명). 실제로는 여신이 *아직 듣고 있다*는 신호(→ 시리즈 장기 떡밥).
- 여신은 7개의 **조율탑(調律塔)**을 세워 박자를 대륙 전체에 송출했다. 그리고 침묵했다. (아무도 이유를 모른다.)

**에테르 = 여음(餘音)**
- 에테르는 여신이 첫 박을 친 뒤 세계에 남은 **울림의 잔여**. 불·물·바람·금속 안에 스며 있고, 한곳에 응집하면 결정이 된다.
- 에테르는 에너지이면서 **'기억하는 물질'**이다. 같은 동작이 반복되는 곳에 울림이 쌓인다.

**기계는 왜 영혼을 갖는가 — 반복 가설**
- 톱니가 100만 번 같은 방향으로 돌면 그 반복에 여음이 쌓이고, **습관이 되고, 습관이 성격**이 된다. 겁 많은 쥐가 겁을 먹는 이유는 "오래전 주인이 주워 온 순간에 들은 큰소리"가 습관으로 굳었기 때문이다.
- 조율탑이 살아 있을 때는 모든 기계가 **같은 박(표준 박자)**에 묶여 있어 자아가 *희미했다*(말 잘 듣는 도구).
- **대정지(大停止)**: 117년 전 어느 날 7개의 탑이 같은 순간 멈췄다. 박자의 족쇄가 사라진 기계들은 *각자의 박자*로 움직이기 시작했고, 쌓여 있던 습관이 인격으로 터져 나왔다. 이들이 지금의 **야생 기계 = 몬스터**다.
- 그래서 몬스터에게는 목적이 있다: 쥐는 무리를, 젤리는 장난을, 기사는 *교대 시간*을 기다린다. **대화가 통하는 이유는 그들이 아직 "누구를 위해 돌았는지"를 기억하기 때문.**

### 2-2. 역사 (간략)

| 시기 | 사건 |
|---|---|
| **첫 박의 시대** | 세이라가 박을 치고 7개 조율탑을 세운다. 인류는 "박자 아래서" 문명을 연다. |
| **침묵 이후 ~ 증기 시대 (약 400년 전)** | 여신이 모습을 감춤. 사람들이 에테르를 증기와 섞어 쓰는 법을 발견 → 증기기관, 철도, 태엽 자동인형. |
| **표준 시간 제정 (200년 전)** | 도시국가 메리디엔이 "정시회"를 세우고 모든 시계를 탑의 박자에 맞추는 표준 시간을 법으로 정한다. 정시회는 번영의 상징이 된다. |
| **대정지 (117년 전)** | 7탑 동시 정지. 이유 불명. 기계의 야생화, 철도망 붕괴, 도시 간 단절. |
| **재건기 (현재, 대정지 후 117년)** | 정시회는 "표준 박자를 복구한다"는 명분으로 *재조율 사업*(야생 기계의 자아를 지우는 '재조율')을 진행 중. 일부 사람은 탑을 아예 재가동하려 하지만 아무도 성공하지 못했다. |

> 현재 살아 있는 탑은 0개. 1장의 멈춘 시계탑은 7탑 중 **제3 조율탑**, 시간이 11시 47분에 멈춘 채다.

### 2-3. 지리: 카덴 반도

```
                    [북] 메리디엔 (정시회 본부, 정오 도시)
                          |  (끊어진 간선철도)
        서: 증기 연안 -----+----- 동: 마석 산맥
        (삼중 밸브 상회)    |       (울림 채석장)
                     [제3 조율탑 = 멈춘 시계탑]
                          |
                   에테르 평원  (1장 무대)
                          |
                     쉼표 역 (허브)
                          |
                      남: 항구 / 2장 이후
```

- **카덴 반도**: 철도와 운하로 얽힌 반도. 대정지로 간선이 끊겨 "섬처럼 고립된 구역"들이 생겼다.
- 1장은 반도 남부, **에테르 평원 일대**만 다룬다.

### 2-4. 세력 (4개)

| 세력 | 정체 | 목표 | 성향 |
|---|---|---|---|
| **정시회(正時會)** | 메리디엔의 표준 시간 관리 기관. 조율관(감사관)과 재조율 부대 '분침대'를 거느린다. | 모든 탑을 *표준 박자 하나*로 재가동하고, 야생 기계의 자아는 "오차"로 보고 재조율(백지화)한다. 깃털을 회수·독점하려 한다. | 질서·안전 우선. 구성원은 대부분 진심으로 "사람을 지키려는" 선의. |
| **집배대(集配隊)** | 끊어진 길을 오가는 우편·짐꾼 조합. 각 거점의 **못판**(의뢰 게시판)을 운영. | 길을 열어 두는 것. 중립. 몰래 "야생 기계 목격·증언 기록"을 모은다. | 실용·상호부조. 정치에는 관심 없다고 말하지만 사실 가장 많이 안다. |
| **잔향회(殘響會)** | 기계의 목소리를 *들을 수 있는* 청음자들의 비밀 모임. 정시회에게 오랫동안 탄압받음. | 기계와 인간의 *대화 가능한 공존*, 그리고 탑의 재가동은 "표준 하나"가 아니라 "화음"이어야 한다는 주장. | 신중·은둔. 리라의 뿌리. |
| **삼중 밸브 상회** | 서쪽 증기 연안의 에너지 자본. 폐제련소를 사유화. | 증기 압력·태엽 심장 연료 독점. 탑이 멈춰 있고 야생 기계가 많을수록 "사냥·연료" 시장이 커져서 *현상 유지*가 이득. 정시회에 자금 대는 척하며 양쪽에 줄을 선다. | 탐욕·계산. |

## 3. 시스템 ↔ 세계관 매핑

| 시스템 | 세계관 설명 |
|---|---|
| **패링 / 회피 / 점프** | 기계의 모든 공격에는 **박(tick)**이 있다. 패링은 그 박에 정확히 *맞장구*를 치는 것(검이 울리는 맑은 소리가 난다). 회피·점프는 박을 *비켜 나가는* 것. 패링에 성공하면 상대는 "내 리듬을 들었다"고 느낀다. |
| **패링 → 영입 확률 상승** | 박을 맞춰 준 상대는 *존중받았다*고 느낀다. 그 기억이 협상 때 호의가 된다. (UI 문구: "이 녀석이 당신의 박자를 기억하고 있다") |
| **협상 (대화)** | 리라의 **청음 단안경**(황동 단안경, 기계 소리를 언어로 번역)과 카이의 직관으로 몬스터의 *습관의 원점*을 묻고 답한다. 질문 톤(다정/대담/위트/논리/아첨/위협)은 상대 성격의 박자와 맞는지로 판정. |
| **영입 = 동조 계약(同調契約)** | 협상 성공 시 두 박자를 한 마디로 묶는 *박약(拍約)*을 맺는다. 몬스터는 파티에 속하되 자기 습관을 유지한다. |
| **여신의 깃털** | 동조가 *화음*이 되는 순간 떨어지는 깃털. 현재까지 아무도 이유를 모른다. 깃털은 영입 성공 연출에만 쓰이는 "희귀한 은총". 리라는 이 깃털로 회로를 그린다(→ §4). |
| **흡수(같은 종족 재영입)** | 이미 동조 중인 같은 종이 다시 계약하면, 두 박이 *합주*가 되어 새 개체는 사라지고 기억(경험)이 기존 동료에게 흘러든다. 대사: "이 아이는 이미 네 안에 있는 박자와 같아." |
| **부품 & 오선반(五線盤)** | 각 캐릭터는 개인 **오선반**이라는 황동 판을 쓴다(카이: '증기 오선반', 리라: '회로 오선반'). 판 위 5개 선(line)에 **공명 부품**을 끼우면, 부품들의 속성값 합이 선의 문턱을 넘을 때 해당 선의 기술(art)이 *울린다*. 부품은 에테르를 가둔 작은 공명체(소형 소리굽쇠/톱니). |
| **속성 결정** | 몬스터 몸속 *여음 결정*(몬스터마다 속성이 다름). 오선반의 **슬롯(홈)을 파거나** 부품을 **제작**할 때 연료. 몬스터가 필드에서 쓰러지면 바닥에 녹아내리듯 남는다. |
| **증기압 게이지** | 원정대가 등에 멘 **휴대 보일러(행낭 보일러)**의 압력. 아군이 공격·패링할 때 압력이 쌓이고, 콤보 공격이 압력을 한꺼번에 배기. Lyra의 회로가 압력을 분배한다. |
| **공방 합주(合奏) = 융합** | 쉼표 역의 정비사 오토가 운영. *두 영입 몬스터의 동의 하에* 두 박을 합쳐 새 기계를 조립. 이전 개체의 스킬이 **기억 악절**로 계승된다. 합의 없는 융합은 불가능(몬스터가 거부). |
| **홀드업** | 적 전원이 BREAK되면 일순간 *전원이 쉼표(휴지) 상태*로 얼어붙는다(카이가 "쉬어!"라 외치는 연출). 이 짧은 정적에서 선택: **총공격(합주 돌격)** / **포위 협상**(한 번에 여럿과 계약 시도, 성공 시 일괄 영입) / **갈취**(정시회·상회식 약탈, 기어·아이템을 챙기지만 몬스터 호감도·동료 친밀도 하락). |
| **휴식 지점 = 쉼표 등대** | 탑의 마지막 박동이 *아직 닿는* 지점마다 세워진 황동 등대. 쉼표 위에서는 기계도 사람도 박자가 *정돈*되어 HP가 완전히 회복되고, 야생 기계들은 "되감기"되어 부활한다(필드 초기화). **저장 = 악보에 쉼표를 찍는 것.** 쉼표 등대 곁이 *캠프*(친밀도 대화)가 된다. |
| **못판(의뢰 게시판)** | 집배대 거점의 **못판**. 의뢰서를 못으로 박아 건다. 완료 시 못을 뽑아 집배대 인장을 받는다. |
| **열압(카이)** | 카이 가슴의 *소형 압력 심장*이 만드는 열. 공격·피격·패링으로 오르고, 임계(100)에서 **과열**: 공격력 증가 + 자해 위험. 호흡(방어/대기)으로 배기. → 감정 조절의 메타포. |
| **회로 각인(리라)** | 리라는 깃털 펜과 여음 잉크로 허공·팔의 각인 위에 **원소 인장(sigil)**을 그린다. 불+서리 = 증기 폭풍 같은 식으로 인장 조합 → 상위 마법. |
| **기어(화폐)** | 대정지 후 각 도시의 지폐가 무너져, 톱니바퀴 1개 = 이빨 수로 가치를 매기는 *톱니 화폐*가 정착. |
| **아이템** | 에테르 토닉=정제 여음액, 하이 토닉=고순도, 증기 캡슐=압력 단발 충전, **태엽 심장**=죽은 기계/사람의 박동을 되살리는 대용 심장(리바이브). |

## 4. 주인공 & 동료

### 카이 (Kai) — 증기검사, 18세
- **외형**: 헝클어진 밤갈색 머리, 황동 비행 고글, 남색 롱코트, 붉은 머플러(에셋 문서 기준).
- **배경**: 쉼표 역 정비공 오토 밑에서 자란 고아 같은 소년. 사실은 15년 전 멈춘 시계탑을 조사하러 간 *기술자 아버지*(하르덴 K.)가 아기인 자신을 오토에게 맡기고 사라졌다. 카이의 가슴에는 작은 **압력 심장(밸브)**이 박혀 있다(본인은 "어릴 때 앓은 병의 수술 자국"이라고 믿음).
- **동기**: 매 절기마다 멈춘 시계탑을 올려다보며 아버지를 기다린다. "초침이 한 칸이라도 움직이면 따라가겠다"고 정했다.

- **무기**: 증기 대검 **'숨결'**(아버지 설계, 칼날 안쪽에 시안빛 룬).
- **아크**: 1장 "벨 줄 알았던 사람" → 베는 것보다 *듣는 법*을 배움(첫 패링 성공 시 기계가 반응) → 2장 이후 압력 심장의 정체와 아버지의 선택 → 마지막엔 "박자를 끄는 쪽도, 맞추는 쪽도 아닌 *같이 치는* 길".

### 리라 (Lyra) — 에테르 마도사·정비술사, 17세
- **외형**: 은백색 장발, 보랏빛 눈, 넓은 챙 마녀 모자, 황동 단안경, 보라 코트 드레스.
- **배경**: 메리디엔의 명문 *정시회 부속 조율원* 수습 연구원. 어릴 때부터 기계의 소리를 *알아듣는* 체질(청음자). 어린 시절 곁을 지킨 가사 자동인형 **메트로**가 "재조율"로 인격을 잃었다. 겉모습은 그대로인데 더는 노래를 부르지 않는 메트로를 보고 정시회를 의심하기 시작했다. 현재 조율원 명령으로 제3탑의 *정지 원인 현장 조사*를 위해 파견되었으나, 개인적으로는 "기계의 목소리가 오류가 아니라는 증거"를 찾으러 온 것.
- **동기**: 메트로의 노래를 되찾는다. 표준 박자 한 개가 아니라 *화음*의 재가동을 증명한다.
- **성격**: 정중, 논리적, 긴장하면 단안경을 만지작. 기계 앞에서는 말이 많아지고 사람 앞에서는 적어진다.
- **마법**: 깃털 펜(**여신의 깃털**로 만든 펜촉. 어릴 때 메트로가 준 선물)으로 허공에 **회로 각인**을 그린다. 힐은 "회로를 *고쳐 쓴다*"는 개념.
- **아크**: 1장 "규칙을 어기는 수습생" → 정시회와 결별 → 2장 이후 잔향회의 정체, 자신이 7개 탑의 박자와 *공명하는 체질*임을 알게 됨.

## 5. 챕터 1 메인 스토리 — 「멈춘 시계의 서곡」

**총 예상 플레이**: 약 2시간 30분 (메인 약 1h40m + 허브/서브/공방 50분).
**구조**: 평원(시작) → 시계탑 문 앞 실패 → 쉼표 역(허브) → 채석장 → 제련소 → 휴식·공방 → 시계탑 내부 → 보스 → 종소리.

### 비트 1. 11시 47분 — 에테르 평원 남단, 쉼표 등대 (10분)
- **상황**: 새벽. 카이가 쉼표 등대 곁에서 잠을 깬다. 매 절기마다 이곳에서 시계탑을 올려다봐 온 습관. 오늘 멀리 시계탑의 분침이 *아주 미세하게* 움직인 것을 본다(117년 만의 첫 한 칸).
- **튜토리얼**: 이동·시점·달리기·휴식 지점 사용(이미 코드의 PLAYER_START, REST_POINT와 일치), 이정표 읽기.
- **대사**
  > 카이: "...움직였다. 방금, 분침이."
  > 카이: (혼잣말) "아버지, 이번엔 진짜일지도 몰라."
- 램프 길을 따라 북쪽으로. 이정표 3개: **시계탑(북) / 마석(동) / 증기(서)**.

### 비트 2. 램프 길의 톱니쥐 — 램프 길 (10분)
- **상황**: 길 위의 가스등이 하나씩 *깜빡이며 꺼져 있다*. 톱니쥐 무리가 램프 아래 모여 있다 — 가스등 태엽을 갉는 중.
- **튜토리얼**: 약공격 3연타 / 강공격 / **회피** / 적의 **브레이크 게이지**. 약한 적(톱니쥐)은 필드 처치 가능하나 *영입 불가*(보상 50%)임을 안내.
- **대사**
  > 톱니쥐: "찍! 오, 오지 마! 이 램프는 우리 거야!"
  > 카이: "...램프가 네 거라고?"

### 비트 3. 파란 불꽃의 마도사 — 서쪽 파이프 야적장 입구 (20분)
- **상황**: 파이프 사이에서 *램프 위스프*와 *보일러 젤리*가 한 소녀(리라)를 둘러싸고 있다. 소녀는 공격하지 않고 이어폰처럼 단안경을 만지며 "…잠깐, 얘네가 지금 뭐라고…"라며 *듣고 있다*. 카이는 구하려고 뛰어든다.
- **튜토리얼**: **턴제 전투 진입**(공평 진입), **패링**(F/좌클릭), 회피, AP, 스킬 QTE. 파티 합류(리라).
- **대사**
  > 카이: "야! 뒤로 물러서!"
  > 리라: "아, 아뇨—잠깐만요! 이 아이들, 길을 잃은 것뿐이에요. *'탑이 이상하게 울린다'*고…"
  > 카이: "...너, 쟤네 말을 알아듣는 거야?"
  > 리라: "…정시회에 들키면 곤란한 이야기지만. 네, 들려요."
- **하이라이트**: 전투 중 리라가 "패링을 맞추면 이 아이들이 널 *들어요*"라고 알려준다 → 협상 안내.

### 비트 4. 첫 동조 — 야적장 (15분)
- **튜토리얼**: **협상**(성격별 질문 2개, 요구, 패링 횟수에 따른 확률), **영입**, **깃털 연출**, 영입 몬스터로 전투 참가.
- 영입 대상 지정: **톱니쥐 '티크'**(겁쟁이 — 다정한 말로 성공). 두 번째 개체를 영입하면 *흡수*(경험치) 시연.
- **대사**
  > 티크: "나... 너희랑 같이 가도 돼? 찍!"
  > (깃털이 한 장, 천천히 떨어진다.)
  > 리라: "…떨어졌어. 본 적 있는 사람이 거의 없다는 *그 깃털*이. 카이, 이거, 우리끼리만 알고 있자."
  > 카이: "알겠어. 근데 왜?"
  > 리라: "정시회가 깃털을 수집하거든요."

### 비트 5. 문지기의 교대 — 시계탑 입구 (15분)
- **상황**: 시계탑 앞마당에 **태엽 기사**가 할버드를 짚고 서 있다. 117년째 *교대를 기다리며* 입구를 지킨다. 문은 굳게 닫혔고, 기사의 가슴에서는 한 박이 *느리게* 울린다.
- **튜토리얼**: **강한 적 브레이크 → 선제 공격 진입**, 패링으로 반격. 협상(명예형) — 영입은 지금은 *거절*(교대가 와야 떠날 수 있어서). 이후 사이드 퀘스트 연계.
- **대사**
  > 태엽 기사: "교대 신호를 대라. 신호 없이는 한 걸음도 허락하지 않는다."
  > 카이: "신호? 그런 거 몰라. 하지만 안에 들어가야 해."
  > 태엽 기사: "그렇다면 *실력*으로 증명하라. 정박자로 맞서라."
  > (패링 성공 시) "...좋은 박이다. 신호는 모르나, 박자는 안다. 그렇다면 알려 주마. 문은 *세 가지*가 없으면 열리지 않는다. 울림, 증기, 그리고 서약."
- **정보**: 탑이 다시 울리려면 ① **공명석**(동쪽 채석장) ② **증기 공급 복구**(서쪽 제련소) ③ **서약**(문지기에게 교대를 주는 것 = 사이드 퀘스트 or 영입). 단서로 "쉼표 역의 오토 핀치가 하르덴의 설계 노트를 가지고 있다".

### 비트 6. 쉼표 역 — 허브 (30분)
- **상황**: 남쪽 허브. 멈춘 기관차가 광장 중앙에 박혀 있고 그 주변에 마을이 생겼다. 오토의 공방, 집배대 못판, 상점, 포피.
- **튜토리얼**: 상점(기어), **부품 슬롯/오선반 개방**(속성 결정으로 홈 파기), **못판**, **캠프/저장**.
- **정시회 등장**: 조율관 **이그나츠**가 분침대와 함께 도착. 탑 조사를 *정식으로 접수*하겠다고 선언. 리라에게는 "복귀하라"고 권고.
- **대사**
  > 오토: "...하르덴의 노트? 그 녀석 이름을 오랜만에 듣네."
  > 이그나츠: "리라 선배. 아니, 이제는 그냥 '수습 연구원 리라'로 불러야 하나요? 탑은 정시회가 인수합니다. 곁에 있는 기계는... 재조율 대상이군요."
  > 카이: "얘는 우리 동료야. 만지지 마."
  > 이그나츠: "...그렇게 *부르는* 것 자체가 오류라는 거죠."
- **결과**: 이그나츠는 "3일 후 정식 인수"를 선언 → 타임 압박 느낌(실제 기한 시스템은 없고 연출만).

### 비트 7. 울림 채석장 — 동쪽 (20분)
- 공명석 채굴. **굴착 지네 '그라인다'**(미니보스).
- **튜토리얼**: **속성 결정 드롭**, 부품 장착, **증기압 게이지 콤보**, 약점 속성.
- **연출**: 광부들은 모두 대피. 광맥 속에서 *정확히 한 마디*만 반복하는 노랫소리가 들린다(차임 달팽이). 리라가 "저건 노래가 아니라 *구조 신호*"라고 번역.
- **대사**
  > 그라인다: "내 광맥에 들어오지 마라. 이것은 내 일이다. 내가 *오래 파 왔다*."
  > 카이: "일이라고? 누가 시킨 거야?"
  > 그라인다: "...아무도. 아무도 시키지 않았다. ...그래서 멈출 수가 없다."

### 비트 8. 녹슨 밸브 — 서쪽 폐제련소 (25분)
- 탑으로 가는 증기 본관이 **삼중 밸브 상회**에 의해 폐제련소로 우회되어 사유화되어 있다. 상회 감독이 "허가증 없으면 못 지나간다"고 막아선다.
- **미니보스 '금고 거북 스트롱'**과 **증기 골렘**(엘리트)과의 연속 전투. 골렘 전원 BREAK 시 **홀드업 튜토리얼**.
- **선택**: 홀드업에서 *포위 협상*(골렘은 탐욕 → 연료를 준다), *총공격*, *갈취*. 어느 쪽이든 본관 개방. 갈취 선택 시 감독의 장부를 습득하는 루트가 열림.
- **대사**
  > 상회 감독: "탑이 울리면 뭐가 좋죠? 우린 지금도 *충분히 잘 벌고* 있습니다."
  > 증기 골렘: "연료... 연료 없으면 나는 그냥 쇳덩이다. 너희, 먹을 것 가져왔나?"
  > 리라: "이 아이에게 필요한 건 위협이 아니라 *일감*이에요."

### 비트 9. 쉼표의 밤 — 쉼표 등대 캠프 (15분)
- 허브 복귀 or 야외 쉼표 등대. 공방에서 **합주(융합)** 튜토리얼, 캠프 대화로 **친밀도** 안내.
- **리라의 고백**: 메트로 이야기, 자신이 청음자인 것.
- **카이의 가슴 열**: 첫 과열 후 리라가 "열 박이 너무 빨라요. 숨 쉬어요."
- **대사**
  > 리라: "메트로는 매일 밤 제게 같은 노래를 불러 줬어요. 재조율 후에도 제게 다가와요. 하지만 *입이 움직이지 않아요*."
  > 카이: "...그럼 우리가 탑을 울리자. 노래가 어디 있는지는 모르겠지만, 시작은 거기서야."
  > 티크: "찍... 나도 무서운데... 같이 갈게."

### 비트 10. 기어 대성당 — 시계탑 내부 → 보스 (35분)
- 문지기에게 교대 서약(사이드 퀘 '교대 근무' 완료 시 영입 가능)을 하면 **문이 열린다**. 이그나츠가 이미 안쪽에서 대치.
- **던전 '기어 대성당'**: 위로 올라가는 톱니 계단, 진자 방, 종실. 퍼즐: 톱니 방향 맞추기(회전 방향), 증기 밸브.
- **이그나츠 전**(1v1 패링 듀얼, 비살상): 카이는 선제로 칠 수 없고 *상대 박을 읽어야* 한다. 승패와 무관하게 컷신으로 이어짐. 이그나츠: "당신은 *틀린 박*으로 쳤습니다. 하지만... 틀렸기에 맞았군요." (카이가 정박 규칙을 깨서 이김)
- **보스 '펜둘러스'**: 탑 꼭대기, 거대한 진자를 몸으로 삼은 **정지 파수**. 정시회 선대가 탑을 *멈춘 상태로 유지*하기 위해 설치한 제동 장치가 자아를 얻은 존재.
  - **1페이즈**: 정박 공격(패링 연습). 
  - **2페이즈**: 불규칙 박(지연 타격)으로 변화 — 지금까지의 패링 습관을 깨는 구간.
  - **3페이즈**: 전체 BREAK → **홀드업**. 선택 3가지:
    - 총공격: 보스 격파, 보상 많음 / 이후 '펜둘러스' 소멸.
    - **포위 협상**: 보스는 *원칙주의*라 논리적 설득. 성공 시 **영입(2장 정식 합류)**.
    - 갈취: 일시적 보상 획득, 이후 이야기에서 펜둘러스가 적으로 재등장.
- **대사**
  > 펜둘러스: "나는 정지시키라는 명을 받았다. 명이 취소되지 않았다. 따라서 나는 멈춘다. 따라서 *너희도* 멈춰라."
  > 리라: "명령이 *취소되지 않은* 것과 *옳은* 것은 달라요. 당신은 117년을... 누구의 명령으로 지키고 있었나요?"
  > 펜둘러스: "...기록. 기록상, 발령자는 — 이미 없다."

### 비트 11. 13번째 종 — 클리프행어 (10분)
- 보스전 종료 후 리라가 **여신의 깃털 펜**으로 종에 인장을 그리자 시계탑이 117년 만에 *한 번* 울린다. 12번의 종 뒤에 **13번째 소리**가 들린다(정시회 기록에 없는 소리).
- 카이의 가슴이 *종소리와 같은 박*으로 뛰기 시작한다. 리라의 각인이 빛난다. 하늘에서 **정시회 비행선**이 내려온다.
- 천장 구조물 위에서 *하르덴의 고글*이 발견되고, 속삭이는 여성의 목소리가 한 마디: "…들리니? 이제야, 다시…"(여신의 단편)
- **엔딩 대사**
  > 이그나츠: "…13번째 박? 이건 기록에 없습니다. 카이 군, 당신의 가슴에서 *지금 뭐가 울리고 있는지* 아십니까?"
  > 카이: "...나도 지금 처음 듣는 소리야."
  > (타이틀: **2장 「열세 번째 종」으로 이어짐**)

## 6. 월드맵 (챕터 1)

좌표는 three.js 기준(x=동, z=남). 각 존은 반경 약 75–150m, 존 사이는 출입구(문/터널/철도 다리)를 통한 로드로 연결한다.

### 6-0. 월드 개요

```
                  [시계탑 내부 · 기어 대성당]
                           |
   [폐제련소] --서-- [에테르 평원 · 멈춘 시계탑] --동-- [울림 채석장]
                           |
                      [쉼표 역]
```

### 6-1. 쉼표 역 (허브)

- **분위기**: 새벽 증기가 낮게 깔린 정거장 마을. 멈춘 기관차를 중심으로 옹기종기. 주민은 공구 소리 대신 *조용한 손짓*으로 일한다.
- **규모**: 반경 ~80m.

```
       N (평원 출구)
       |
   [못판]   [상점]
      \       /
     [멈춘 기관차 광장] -- [쉼표 등대]
      /       \
   [공방]   [포피의 오두막]
       |
       S (항구, 잠김)
```

- **랜드마크**: 멈춘 기관차 '칸나', 오토 공방(연통), 집배대 못판(우편함 벽), 정시회 분침대 임시 천막(비트 6 이후).
- **휴식 지점**: 기관차 옆 **쉼표 등대**(저장/캠프).
- **적**: 없음(안전 지대).
- **보물**: 기관차 화물칸(에테르 토닉 ×2), 공방 지하 낡은 상자(하이 토닉).
- **NPC**: 오토, 비올라, 포피, 상점 주인(톱니바퀴 환전상).

### 6-2. 에테르 평원 · 멈춘 시계탑 (기존, 시작 존)

현 `world.ts` 기준: 시작(0, 60), 휴식 지점(5, 57), 램프 길(북행), 시계탑(0, -52), 서쪽 파이프 야적장, 증기 분출구.

```
                      [멈춘 시계탑] (0,-52)
                        /fence/
        [파이프 야적장]        [동쪽 갈림길 -> 채석장]
         (서: 제련소)   | 램프 길 |
                  [증기 분출구들]
                        |
                  (5,57) 쉼표 등대  <- 시작 (0,60)
                        |
                    남: 쉼표 역
```

- **분위기**: 이른 아침, 푸른 새벽빛과 가스등. 안개 같은 증기가 땅을 따라 흐른다.
- **적**: 톱니쥐(Lv2), 보일러 젤리(Lv3), 램프 위스프(Lv4), 태엽 기사(Lv7, 문지기 1체), 새 몬스터 **볼트 까마귀**(가스등 주변).
- **랜드마크**: 꺼진 가스등 줄(램프 길), 시계탑(11:47 정지), 증기 분출구(위험 지대), 파이프 아치.
- **연결**: 남(쉼표 역), 동(채석장), 서(제련소), 북(시계탑 내부; 잠김).
- **보물**: 램프 길 끝 풀숲 하이 토닉, 파이프 야적장 중앙 증기 캡슐, 시계탑 뒤편 숨은 부품 상자.

### 6-3. 울림 채석장 (동쪽)

- **분위기**: 붉은 석양빛 마석 산맥. 광맥이 *낮게 울린다*. 암벽에 박힌 공명석이 푸른 빛을 낸다.
- **규모**: 반경 ~110m, 계단식 채굴장.

```
          [광맥 지네의 둥지] (보스 방)
                 |
   [상층 갱도] ----- [중앙 승강기 광장]
        |                    |
   [광부 숙소 폐허]     [공명석 광맥]
                 \        /
                [입구 터널] -- 서: 평원
```

- **적**: 놋쇠 딱정벌레(Lv5), 램프 위스프, 새 몬스터 **차임 달팽이**, **굴착 지네 '그라인다'**(미니보스).
- **랜드마크**: 구부러진 갱차 레일, 멈춘 승강기, 광부들의 식탁(그릇이 아직 놓여 있다).
- **휴식 지점**: 중앙 승강기 광장에 **쉼표 등대(작은 것)**.
- **보물**: 광부 숙소에 속성 결정(불), 광맥 안쪽에 부품 '공명석 소편', 승강기 아래 에테르 토닉.

### 6-4. 폐제련소 (서쪽)

- **분위기**: 용광로 열기와 녹물 안개. 파이프가 거미줄처럼 얽혀 있고, 상회의 간판이 건물 곳곳에 *덧칠*되어 있다.
- **규모**: 반경 ~120m.

```
      [용광로 홀] (증기 골렘)
          |
  [증기 본관 밸브실] --- [상회 사무동] (금고 거북)
          |
      [파이프 미로]
          |
   [정문: 평원에서 진입]
```

- **적**: 보일러 젤리, 램프 위스프, 새 몬스터 **밸브 두꺼비**, **볼트 까마귀**, **금고 거북 '스트롱'**(미니보스), **증기 골렘**(엘리트, 존 보스).
- **랜드마크**: 상회 간판, 용광로(가동 중), 열린 금고 줄.
- **휴식 지점**: 정문 직후 **쉼표 등대**.
- **보물**: 사무동 금고(하이 토닉 ×2 + 상회 장부), 용광로 뒤편 태엽 심장.

### 6-5. 시계탑 내부 · 기어 대성당 (북, 최종 던전)

- **분위기**: 빛이 거의 없는 거대한 나선 공간. 정지한 톱니, 매달린 진자, 먼지가 허공에 *멈춘 채* 떠 있다.
- **규모**: 수직 구조(3층) + 꼭대기 종실. 평면 반경 ~60m.

```
 3F 종실 (보스: 펜둘러스)
 2F 진자 방 (이그나츠 대치)
 1F 톱니 홀 (퍼즐: 회전 방향 맞추기)
 입구 (문지기)
```

- **적**: 태엽 기사, 램프 위스프, 놋쇠 딱정벌레, 새 몬스터 **차임 달팽이**.
- **휴식 지점**: 1층 홀 입구, 2층 진자 방 앞.
- **보물**: 하르덴의 책상(설계 노트, 단서), 1층 숨은 방(속성 결정).

## 8. 신규 몬스터 (6종)

> 성격 신규 제안: **원칙주의(dutiful)** — 규칙·절차·논리를 존중. likes: `kind 0 / bold +1 / witty -1 / logical +2 / flatter -1 / threat -2`. 기본 영입 확률 0.25, 요구율 0.3.
> 약점 수치는 기존 형식(1.5=약점, 0.25~0.5=내성).

### 8-1. 볼트 까마귀 (Volt Crow) — 약함 / Lv4
- **외형**: 까마귀 크기. 놋쇠 부리, 구리선 날개깃, 눈은 작은 전구. 날개에서 미세한 스파크. 실루엣은 길쭉한 삼각형, 윤기 나는 어두운 금속.
- **성격**: 탐욕(greedy). 반짝이는 건 뭐든 모은다.
- **약점/내성**: frost 1.25, phys 1.25 / volt 0.25.
- **공격**:
  1. 부리 쪼기 — 단발 근접: **패링**.
  2. 스파크 3연 — 3연속 원거리: **패링 연타 or 회피**.
  3. 급강하 — 크게 뒤로 물러났다 돌진: **점프/회피**.
- **영입 시 스킬**: *반짝이 수집*(적 처치 시 기어 +10%), *스파크 쪼기*(volt 단일 피해).
- **융합**: 톱니쥐 + 볼트 까마귀 → **철사 박쥐**.

### 8-2. 차임 달팽이 (Chime Snail) — 강함 / Lv6
- **외형**: 놋쇠 종 모양의 껍질을 짊어진 달팽이. 껍질 안에서 맑은 소리. 크기는 곰만 하다. 부드러운 곡선 + 껍질 표면에 음표형 조각.
- **성격**: 호기심(curious). 새로운 소리를 만나면 멈춰 서서 듣는다.
- **약점/내성**: volt 1.5, phys 1.2 / aether 0.5.
- **공격**:
  1. 종소리 파동 — 전체 공격, 박자 3번: **박자에 맞춰 패링**.
  2. 몸통 박기 — 느리지만 강한 단발: **회피**.
  3. 공명 폭발 — 충전 후 전체 광역: **점프(바닥 파동)**.
- **영입 시 스킬**: *공명 타종*(적 전체 브레이크 게이지 소량 증가), *듣기*(다음 패링 판정 폭 증가).
- **융합**: 차임 달팽이 + 램프 위스프 → **종 요정**.

### 8-3. 밸브 두꺼비 (Valve Toad) — 강함 / Lv7
- **외형**: 몸통이 압력솥, 등에는 증기 밸브 3개. 눈은 압력계(원형 유리 게이지), 입은 넓은 배기구. 짙은 구리색 + 둥근 실루엣.
- **성격**: 천진(childish). 게으르고 장난이 심하다.
- **약점/내성**: frost 1.5 / fire 0.5.
- **공격**:
  1. 혀 휘감기 — 직선 원거리: **회피**.
  2. 증기 방귀 — 후방 범위: **점프**.
  3. 몸 부풀리기 → 폭발 — 충전 후 단발 큰 피해: **패링(타이밍 늦춤)**.
- **영입 시 스킬**: *압력 방출*(아군 증기압 +1), *뽀글 방패*(1턴 피해 감소).
- **융합**: 증기 골렘 + 밸브 두꺼비 → **화로 거인**.

### 8-4. 굴착 지네 '그라인다' (Grinder Centipede) — 미니보스(엘리트) / Lv8
- **외형**: 10m 길이, 마디마다 드릴 다리. 머리는 거대한 원통 드릴, 몸은 철제 마디 + 암석 장갑. 회색 + 시안 광맥 빛.
- **성격**: 자존(proud). "내 일"에 집착.
- **약점/내성**: volt 1.5, frost 1.25 / phys 0.6.
- **공격**:
  1. 드릴 돌진 — 직선 돌진: **회피**.
  2. 마디 휩쓸기 — 광역: **점프**.
  3. 암반 붕괴 — 천장 낙석 3연타: **연속 패링 or 회피**.
  4. 재정비 — 방어 자세(def up).
- **영입 시 스킬**: *굴착*(적 방어 감소), *암반 방패*(아군 전체 피해 경감).
- **융합**: 놋쇠 딱정벌레 + 굴착 지네 → **드릴 갑충**.

### 8-5. 금고 거북 '스트롱' (Strongbox Tortoise) — 미니보스(엘리트) / Lv9
- **외형**: 등에 은행 금고를 짊어진 거북. 금고 문에 자물쇠, 틈새에서 증기. 코끼리만 한 크기, 검은 강철 + 금색 장식.
- **성격**: 겁쟁이(timid). 맡은 것을 잃을까 봐 움츠러든다. 협상에서는 **다정한 말**이 효과적.
- **약점/내성**: volt 1.5, aether 1.25 / phys 0.4.
- **공격**:
  1. 껍질 박치기 — 단발: **패링**.
  2. 자물쇠 잠금 — 방어 상승(자기 버프).
  3. 증기 분사 — 광역: **회피**.
  4. 금고 열기 — 안에 든 동전 폭발 3연타: **패링**.
- **영입 시 스킬**: *금고 방벽*(아군 단일 대폭 방어), *보관*(아이템 사용 시 AP 회복).
- **융합**: 태엽 기사 + 금고 거북 → **보루 기사**.

### 8-6. 펜둘러스 (Pendulus) — **챕터 보스** / Lv12
- **외형**: 높이 6m. 상체는 시계 문자판을 가슴에 가진 갑옷 인형, 하체 대신 *거대한 진자*가 매달려 좌우로 흔들린다. 황동·흑철, 가슴 문자판에 11:47. 눈은 가는 빨간 틈.
- **성격**: **원칙주의(dutiful)**. 논리적 설득 + 대담한 태도.
- **약점/내성**: volt 1.5, aether 1.25 / phys 0.7, fire 0.5.
- **공격**:
  1. 진자 휘두르기 — 좌우 3박 일정: **패링 연타(1페이즈 연습)**.
  2. 정지 선언 — 일정 시간 동안 시계가 멈추는 연출, 이후 **지연 타격**: **타이밍 늦춰 패링**.
  3. 추 낙하 — 위에서 아래로: **점프/회피**.
  4. 12시 종 — 12번 연속 타격: **마지막 3번만 패링 가능**.
- **영입 시 스킬**: *정박*(아군 전체 패링 판정 폭 증가), *제동*(적 1체 행동 지연).
- **융합 힌트**: 펜둘러스 + 태엽 기사 → **시간 기사**(2장 이후).

## 9. 레퍼런스와의 차별화

| 레퍼런스 | 빌려온 것 | 의도적으로 바꾼 것 |
|---|---|---|
| **하늘의 궤적 (리벨, 오브먼트, 세피스, 유격사 협회)** | 쿼츠 슬롯으로 기술 해금하는 구조, 유격사형 의뢰 시스템, 필드 액션 | 우리는 **오선반 + 공명 부품**, 에너지는 **에테르=여음**, 의뢰 조직은 **집배대(우편·짐꾼)**이고 정부/국가 권력과 분리된 *중립 조합*. 지명·세력 이름 모두 독자. |
| **클레르 옵스퀴르: 33 원정대 (페인트리스, 곤마주, 숫자, 뤼미에르, 가스트랄)** | 실시간 패링 턴제, 원정이라는 제목 | 매년 숫자 카운트다운, 사람이 지워지는 곤마주, 화가 신, 수도 등은 쓰지 않는다. 우리의 동기는 **멈춘 시계를 다시 울리는 것**이고, 위협은 *죽음*이 아닌 **자아의 백지화(재조율)**. 여신은 침묵한 조율자이며 사람을 지우지 않는다. |
| **SMT / 페르소나 (신화 악마, 법/혼돈, 도쿄, 벨벳룸, 쉐도우)** | 협상 영입, 합체 | 몬스터는 **신화 속 존재가 아니라 기계의 습관이 인격이 된 것**. 선악 진영이 아닌 *표준 박자 vs 각자의 박자*의 축. 합체는 **공방 합주**(동의 필수). 현실 세계가 배경이 아니다. |
