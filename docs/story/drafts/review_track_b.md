# 교차 리뷰 — Sonnet안 「멈춘 시계의 서곡」

> 검토 기준: README, docs/FEATURE_RESEARCH.md, src/data/units.ts·world.ts, src/anim/rig.ts, docs/2D_ASSET_PROMPTS.md, docs/ui/UI_BIBLE.md. 비교 대상은 world_opus.md. 인용 표기는 (§절/비트).

## 요약 점수

| 항목 | 점수 |

"음악·박자·쉼표"라는 하나의 언어로 시스템 이름을 꿰어 낸 솜씨는 두 안 가운데 더 낫다. 하지만 우주론의 핵심 전제(탑의 박자가 자아를 억누른다)가 주인공의 목표(탑을 다시 울린다)와 정면으로 충돌하고, 콘텐츠 양이 작은 three.js 프로토타입이 감당할 수준을 넘는다.

## 1. 독창성 — 6/10

**위험 요소**
- **대정지 ≈ 하늘의 궤적 SC의 "도력 정지 현상"**. "7개의 탑이 같은 순간 멈춰 기계가 일제히 멎는다"(§2-1, §2-2)는 구도는 고스펠/오리오르가 일으킨 리벨 전역 도력 정지와 지나치게 가깝다. 숫자 '7'도 셉티움(7속성)을 떠올리게 한다. → **수정안**: 동시 정지를 버리고 "탑이 하나씩 *느려지는* 현상"으로 바꾼다. 아니면 1장 탑 하나의 국지적 정지로 범위를 줄이고, 탑 수는 7이 아닌 숫자(예: 12시를 따서 12)로 한다.
- **오선반 5줄 + 속성 합 문턱 + 결정으로 홈 파기**(§3)는 오브먼트 라인 + 쿼츠 + 셉티스의 1:1 대응이다. 안 스스로 차용을 인정한다(§9). 오선반이라는 이름만으로는 차별점이 약하다. → **수정안**: "같은 *음정*(속성)의 부품이 한 줄에 나란히 놓이면 화음 보너스, 어긋나면 불협 페널티"처럼 배치 순서가 의미를 갖게 만든다. 한 줄 합계만 보는 구조에서 벗어나야 한다.
- **정시회(표준 박자·질서) vs 각자의 박자(자유·위험)**(§1 테마 3, §9)는 안이 부정하는 바로 그 SMT의 Law/Chaos 이분법이다. "선악이 아니다"라는 주장은 SMT의 Law/Chaos에도 똑같이 해당한다. → **수정안**: 제3·제4의 답을 1장부터 보여 준다. 삼중 밸브 상회의 "현상 유지"를 축으로 승격하거나, Opus안처럼 세력별로 기계를 무엇으로 보는지(부품/조각/자치)를 갈라 축을 셋 이상으로 늘린다.
- **홀드업 3지선다(총공격/협상/갈취)**(§3)는 P5와 똑같다. 기획 문서상 차용은 괜찮지만, "쉼표 상태"라는 포장을 연출(전원 정지 + 무음 1초)로 확실히 살려야 한다.
- 33원정대와는 거리를 잘 두었다(§9). 화가 신, 숫자, 곤마주가 없고, 위협이 "죽음"이 아니라 "자아의 백지화"라는 점이 좋다. 다만 "자아를 지우는 재조율"은 페르소나의 '정신 폐쇄'나 니어류 서사와 겹치는 흔한 장치라, 메트로 같은 구체적인 얼굴로 차별화해야 한다(이미 잘 하고 있다).

## 2. 우주론 일관성·메카닉 정당화 — 5/10

**치명적 모순**
- **"탑이 울리면 기계의 자아가 희미해진다"(§2-1)는 설정이 있는데, 1장의 목표와 엔딩이 "탑을 울리는 것"이다(로그라인, 비트 11).** 이 설정대로라면 카이 일행이 종을 칠 때 티크를 비롯한 동료 몬스터의 자아가 흐려져야 한다. 안은 "화음으로 재가동"이라는 개념으로 피해 가지만 1장 안에서는 설명되지 않는다. 플레이어는 "왜 정시회와 같은 일을 하지?"라고 느낀다. → **수정안**: 13번째 종을 "표준 박이 아닌 첫 화음"이라고 비트 11에서 명시한다. 그리고 종이 울린 뒤 티크가 오히려 *더 또렷해지는* 연출을 넣는다.
- **펜둘러스의 출신**(비트 10, §8-6): "정시회 선대가 탑을 *멈춘 채로 유지하려고* 설치한 제동장치"라는데, 정시회의 공식 목표는 탑 재가동이다(§2-4). 정시회가 대정지를 일으켰다는 반전이라면 1장에서 단서 하나는 줘야 한다. 그렇지 않으면 그냥 오류로 읽힌다.
- **깃털의 희소성**: "본 적 있는 사람이 거의 없다"(비트 4)고 하면서 리라는 어린 시절 가사 인형에게서 받은 **여신의 깃털 펜**을 쓴다(§4). 희소성과 연출이 동시에 무너진다.

**작은 오류**
- 로그라인은 "130년 전", 본문은 "117년 전"이다.
- 이그나츠는 "리라의 조율원 선배"(§4 표)인데 리라를 "리라 선배"라고 부른다(비트 6). 30대인 그가 17세 리라의 후배라는 설정도 어색하다.
- 이그나츠는 "3일 후 정식 인수"를 선언했는데(비트 6), 비트 10에서는 이미 탑 안에 있다.
- 신규 성격 '원칙주의(dutiful)'(§8)는 기존 '기사도(honorable)'와 역할이 겹친다. 대담/논리 중 무엇을 선호하느냐만 다르다.

**메카닉 정당화 (잘된 것 / 약한 것)**

## 3. 기존 에셋·콘텐츠 적합도 — 7/10

- **좋음**: 태엽 기사 "교대를 기다린다"(비트 5)는 units.ts의 설명 "멈춘 시계탑을 지키던 자동인형"과 딱 맞는다. 증기 골렘을 폐제련소에 둔 것은 "폐공장의 용광로가 깨어난 거인"과 일치하고, 램프 위스프 가스등 퀘스트(S2)는 "버려진 가스등에 깃든 정령"과 맞는다. 6종 성격도 모두 그대로 쓴다. PLAYER_START·REST_POINT·시계탑 좌표 재사용(§6-2), 카이의 증기 배낭 → 행낭 보일러, `overheat_storm` → 열압, 비행선(props_airship 존재)을 클리프행어에 쓴 것도 좋다.
- **충돌**: ① 리라의 무기. 2D 에셋 프롬프트와 컷인은 **황동 톱니 고리 + 결정 지팡이**인데, 안은 깃털 펜이다(§4). ② UI 모티프 "태엽 계기판 위에 **여신의 깃털**"의 희소성 원칙과 충돌한다(위 참조). ③ 평원 동쪽의 기존 `prop_crystal` 결정 숲과 `prop_gear_monument`(골렘 둥지)를 서사에서 쓰지 않는다. ④ 기존 표지판(시계탑/마석/증기)을 살린 점은 좋다.

## 4. 1장 스토리 — 6/10

- **훅**: "117년 만에 분침이 한 칸 움직였다"(비트 1)는 조용하고 강하다. 메트로 이야기(비트 9)는 이 안에서 가장 좋은 감정선이다. 그라인다의 "아무도 시키지 않았다. 그래서 멈출 수가 없다"와 펜둘러스의 "발령자는 이미 없다"는 반복 가설을 대사로 증명하는 훌륭한 장면이다.
- **분량 오류**: 비트별 시간을 더하면 **205분(3시간 25분)**이다. "메인 1h40m"(§5)과 맞지 않는다. 서브 퀘스트까지 넣으면 4시간이 넘는다.
- **허브 도착이 늦다**: 허브가 누적 70분 시점(비트 6)에 처음 나온다. Opus안은 33분이다.
- **튜토리얼 과밀·순서**: 비트 3 한 곳에서 턴제, 패링, AP, QTE, 리라 합류를 한꺼번에 가르친다. 비트 5에서는 Lv2~3 파티가 Lv7 태엽 기사를 상대하는 난이도 급등이 있다. 또 오선반 홈 파기(허브, 비트 6)를 **속성 결정을 처음 얻기 전**(채석장, 비트 7)에 가르쳐 순서가 뒤집혀 있다.
- **필수/선택 혼동**: 탑 문을 열려면 사이드 퀘스트 '교대 근무'가 필요한 것처럼 쓰여 있다(비트 10). 메인이라면 메인으로 올려야 한다.
- **클라이맥스 과적**: 이그나츠 듀얼, 3페이즈 보스, 홀드업, 13번째 종, 심장 공명, 비행선, 고글, 여신 목소리까지 마지막 45분에 몰려 있다. 떡밥은 두 개(13번째 종 + 카이의 심장)로 줄이고, 고글과 여신 목소리는 2장으로 넘긴다.

## 5. 구현 가능성 — 4/10

| 항목 | 안의 요구 | 비고 |
|---|---|---|
| 존 | 5개(허브, 평원, 채석장, 제련소, 탑 3층 + 종실) | 평원 외에 4개를 새로 만들어야 함 |
| 신규 몬스터 | 6 + **융합 결과 6종**(§8 표) = 12개 모델 | 현재 rig 아키타입은 6종(humanoid/rat/slime/beetle/wisp/golem). 까마귀(새), 10m 지네(마디), 펜둘러스(진자 하체)는 새 아키타입이 필요 |
| 새 전투 모드 | 이그나츠 1v1 비살상 듀얼 | 별도 규칙이라 비용이 큼 |
| 인간 NPC | 이름 있는 인물 약 10명 + 분침대 병사 | 인간 모델은 카이·리라 둘뿐 |
| 퍼즐 | 톱니 회전, 밸브 | 시스템 2개 신규 |

**잘라낼 것**
1. 채석장과 제련소 중 하나를 1장에서 빼거나 둘 다 소형(반경 50m)으로 만든다. 제련소는 기존 `prop_pipe`/`prop_vent`/`prop_crate`만으로 조립 가능하니 남기고, 채석장은 평원의 결정 숲 구역으로 대체한다.
2. 융합 결과는 1장에 1~2개만, 기존 모델을 리컬러해서 만든다.
3. 신규 모델은 아키타입을 재사용한다. 금고 거북은 beetle, 밸브 두꺼비·차임 달팽이는 slime. 까마귀와 지네는 컷하고, 펜둘러스만 유일한 신규 보스 모델로 둔다.
4. 이그나츠는 knight 리그를 쓰는 일반 전투로 처리한다(특수 규칙은 "선제 행동 없음" 정도).
5. 탑 내부는 2층(층 전환 페이드)으로 줄이고, 퍼즐은 하나만 남긴다.
6. NPC는 이름 있는 인물 5명(오토, 비올라, 포피, 이그나츠, 상회 감독)으로 제한하고, 실내 없이 UI 패널로 처리한다.

## 6. 머지할 때 남길 것 / 버릴 것

**강점 5 (유지)**
1. **반복 가설**: "습관이 성격이 되고, 누구를 위해 돌았는지 기억하기에 대화가 통한다"(§2-1). 성격 시스템과 협상의 근거가 된다.
2. **쉼표 언어 체계**: 쉼표 등대(저장·회복·되감기 부활)와 홀드업 = 쉼표 상태.
3. **동의가 필요한 공방 합주 + 기억 악절**.
4. **이그나츠(패링의 거울)와 펜둘러스("발령자는 이미 없다", 2페이즈에서 패링 습관 깨기)**.
5. **리라의 메트로 서사, 태엽 기사 '교대 근무'**. 기존 몬스터 설정에서 자라난 감정선이다.

**약점 5 (버리거나 교체)**
1. 7탑 **대정지**. 궤적과 닮았고, "탑 = 자아 억제"라는 설정이 목표와 모순된다.
2. **깃털 펜 무기와 회로 각인의 깃털 연출**. 에셋, UI_BIBLE, 희소성 원칙을 모두 위반한다.
3. 정시회 vs 자유라는 **Law/Chaos형 2축**.
4. 클라이맥스 과적(듀얼 + 3페이즈 + 떡밥 5개)과 시간 계산 오류.
5. 융합 결과 6종을 포함한 신규 모델 12종과 신규 성격 '원칙주의'의 중복.

**Opus안으로 메울 수 있는 부분**
- **우주론**: "갇혀 연료가 된 여신의 감정 조각이 기령이 된다"(Opus §1-1)를 쓰면 6개 성격이 감정(두려움·장난기·긍지 등)에 체계적으로 대응한다. 깃털도 "자발적으로 손잡을 때 갇힌 여신에게 위안이 전해져 떨어진다"로 설명된다. 반복 가설은 "감정이 *어느 기계에* 고이는지를 정하는 조건"으로 접붙이면 둘 다 살릴 수 있다.
- **탑의 역할**: Opus의 "종소리가 기령을 진정시키는 탑, 정숙 침으로 탑을 멈춘 바일"을 쓰면, 탑을 울리는 일이 억압이 아니라 위안이 되어 모순 1이 풀린다. 악역의 구체적 행위도 생긴다.
- **리라**: 지팡이 + 공명 렌즈(Opus §3-2)는 에셋과 일치한다.
- **도입과 구조**: 기존 `prop_lamp` 6개를 켜는 "점등 순회" 튜토리얼(Opus 비트 1), 33분 만에 허브 도착, 순서를 고를 수 있는 두 던전, 첫 협상 직후 깃털 → 리라 등장(Opus 비트 2~3).
- **구현 메모**: 기존 프롭 재사용 지침과 15개 플래그 기반의 선형 진행(Opus §9).
- **세력 축 확장**: 점등회·수도회·녹청 연대로 Law/Chaos 2축을 깬다. 단, Opus도 세력이 4개라 1장에서는 2개만 얼굴을 보여 주는 것이 좋다.
